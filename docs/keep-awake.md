# DEVICE 防休眠

每个 DEVICE 的“在线配置”和“串口配网”中均可设置防休眠策略。策略保存在 ESP32 的 NVS 中，随设备配置写入并重启生效；旧配置缺少该策略时默认关闭。

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| 启用 | 关闭 | 为此设备启用防休眠 |
| A / B | 30 / 60 秒 | 每次随机选取 [A, B] 内的整数秒作为空闲检查间隔，范围 1～86400，A ≤ B |
| C | 1800 秒 | 此设备连续 C 秒没有主动输入后停止防休眠；0 表示不限 |
| D | 120 秒 | 要求 HOST 最近 D 秒发生过物理键鼠输入；0 表示取消 HOST 活动前提，离线也满足 |

主动操作以通过 EspKVM 发往此 DEVICE 并被 HID 队列接受的键盘状态变化、鼠标移动/滚动/按钮变化和媒体键变化为准。用户操作重置 C，并重新随机选择 A/B 间隔。防休眠移动直接进入独立的模拟移动路径，不会重置这些计时。该 DEVICE 重新收到主动输入后，可以从 C 到期的停止状态恢复。切换目标、释放屏障、重复的空状态、普通心跳和重新连接都不视为新的主动输入。

C 首次从固件启动并加载策略时开始计时，因此启用后即使尚未操作此设备，也有最多 C 秒的防休眠窗口。USB 对端电脑自身连接的其他键鼠不经过 EspKVM，ESP32 无法据此更新 C。

HOST 在所有设备连接的心跳请求和应答中携带物理输入的空闲秒数及是否已观测到输入。操作本机、当前 DEVICE、其他 DEVICE，或切换过程中的物理输入都计入 HOST 活动；状态重同步、故障通知及已识别的软件注入不计入。尚未收到物理输入或采集器失效时，上报活动未知。

D > 0 时，DEVICE 要求最近 3 秒收到过认证心跳，并用心跳中的空闲时间加上已过去的本地时间判断 D。断连会立即取消该 HOST 的活动记录。D = 0 时，不受 HOST 活动或离线状态限制；C 的期限仍然生效。

当随机间隔到期且前提满足时，DEVICE 通过 USB HID 发送 -3～3 的随机 X/Y 相对位移（至少一个轴非零），不发送点击或按键。USB 未就绪、存在排队输入、按键/鼠标按钮/媒体键仍按住时推迟本次移动，条件恢复后立即补上；前提不满足（HOST 心跳超时、HOST 无近期操作、C 到期）时每秒重新检查一次，恢复后 1 秒内移动，不再等待新一轮 A/B 间隔。只有实际发出移动后才重新随机选择下一次间隔。Web UI 显示当前暂停原因和本次启动触发的模拟移动次数。

USB 主机挂起时，DEVICE 保留 USB 枚举状态和 HOST 输入会话，不把睡眠误报为 USB 断开。DEVICE 在配置描述符中声明支持远程唤醒，并在收到切换释放屏障或新的 HID 输入时尝试唤醒 USB 主机；总线恢复后先发送中性报告，再继续输入。远程唤醒是否成功由目标机的操作系统、电源及固件策略决定；未枚举或已断开的 USB 仍不可用。

目标机睡眠时也能切换过去：挂起期间 DEVICE 对 ReleaseAll 立即确认（挂起已清空状态，恢复后先发中性报告），状态中 `usb_suspended=true`，Web UI 显示“睡眠中”，客户端对此设备的释放等待放宽到 20 s。切换完成后，键鼠输入在 DEVICE 上被丢弃，但每次输入（最多每秒一次）都会再次请求远程唤醒。主机唤醒时如复位 USB 总线，DEVICE 在 20 s 宽限内仍报告已挂载且仍在睡眠，保持会话和当前目标，等待重新枚举；超过宽限仍未枚举才按 USB 卸载处理并回 LOCAL。

协议沿用原有字段，新增 `Config.keep_awake`、心跳中的 `host_idle_s` / `host_activity_known`，以及状态中的防休眠状态和计数。旧客户端未提交策略时，设备保留已保存策略。旧设备固件不返回策略字段时，Web UI 会提示升级并禁用策略输入。

针对性验证包括 C 状态机的随机区间两端、主动输入重置、模拟移动不续期、C/D 边界、心跳过期、0 值语义；NVS 默认值迁移、保存重启和省略字段保留；HOST 跨目标活动计数、心跳携带活动和 Web API 保留 C/D 的 0 值。
