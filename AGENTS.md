# Build and flash

Run these commands from Windows PowerShell at the repository root. They use WSL2 for the builds and sync the results into `build/`.

```powershell
wsl.exe bash -lc 'cd /mnt/d/workspace/EspKVM && PROTO_PYTHON="$HOME/.local/opt/ek/proto312/bin/python" bash scripts/wsl/build.sh build host'
wsl.exe bash -lc 'cd /mnt/d/workspace/EspKVM && PROTO_PYTHON="$HOME/.local/opt/ek/proto312/bin/python" bash scripts/wsl/build.sh build device'
```

The HOST executables are written to `build/host/bin/`. The DEVICE build creates a flash package under `build/device/flash/firmware/<package>/`; flash the `firmware` package, not `hid-selftest`.

Connect the ESP32-S3 and find its Windows COM port:

```powershell
Get-PnpDevice -Class Ports -PresentOnly
```

Flash the package generated by the DEVICE build (replace the package directory and COM port as needed):

```powershell
./scripts/windows/flash.ps1 -Package ./build/device/flash/firmware/<package> -Port COM3
```

The flash script validates the package manifest and SHA-256 hashes before writing. If Windows does not enumerate a COM port, reconnect the board/check its USB cable and driver before flashing.
